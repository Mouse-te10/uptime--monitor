# Описание

Данный проект создан на базе таких технологий как HTML, CSS, JavaScript и Docker. Он принимает URL-адрес веб-страницы и через некоторое время отдает ответ от сервера, а именно код ответа от сервера. Данный сайт поможет вам быстро узнать какие url адреса вам доступны, а какие нет.

# Запуск

```bash
docker compose up --build
```
